НАСТАСЬЯ — PWA-прототип v3 (офлайн-версия)

ПУБЛИКАЦИЯ
1. Загрузите содержимое этой папки на HTTPS-хостинг (например, Netlify).
2. Откройте постоянную публичную ссылку в Safari на iPhone.
3. Дождитесь полной загрузки интерфейса. Не закрывайте страницу сразу — дайте Service Worker завершить установку и кэширование.
4. Добавьте приложение: «Поделиться» → «На экран Домой».
5. Запустите приложение с иконки ещё один раз при включённом интернете. Затем проверьте авиарежимом.

ЧТО ИЗМЕНЕНО В v3
- Шрифты для заголовков и интерфейса хранятся в папке assets/fonts и загружаются локально. Интернет для них не нужен.
- Service Worker кэширует HTML, манифест, иконку, логотип и все пять файлов шрифтов. При отсутствии сети открывается сохранённая версия приложения.
- На главной добавлена заметная кнопка создания резервной копии и восстановления.
- Резервная копия включает материалы, изделия, историю, настройки и дату экспорта.
- Увеличено время жизни временного URL файла при скачивании, чтобы Safari успел начать сохранение.

РЕЗЕРВНАЯ КОПИЯ
Нажмите «Сохранить копию» на главной. На iPhone выберите сохранение файла в «Файлы» или другое доступное действие. Для восстановления нажмите «Восстановить» и выберите ранее сохранённый JSON-файл.
Рекомендуется сохранять копию после добавления новых материалов и важных расчётов.

ВАЖНО
- Это устанавливаемое веб-приложение (PWA), а не нативное приложение из App Store.
- Для первой загрузки, установки и получения обновлений нужен интернет. После успешного первого кэширования основные функции работают офлайн.
- Данные хранятся локально в браузерном хранилище на этом iPhone. Облачной синхронизации нет. Резервные копии храните отдельно.
- Не очищайте данные Safari для этого сайта, если хотите сохранить локальные расчёты.
- Для работы Service Worker сайт обязательно должен открываться по HTTPS.
